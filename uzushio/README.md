# 有限会社うずしお食品 コーポレートサイト リニューアル プロトタイプ

`index.html` をブラウザで開くとご覧いただけます（HTML / CSS / JavaScript の静的プロトタイプ、ビルド不要）。

## 主な改善点

- お知らせをファーストビューから外し、ページ下部（⑩）へ移動
- ファーストビュー直後に「3つの強み」を配置し、3秒で事業内容が伝わる構成に
- 商品紹介・製造工程・品質・数字・法人向け(OEM)・会社の想い・お問い合わせの順に情報を整理
- 2015年の古い統計グラフは廃止し、カード型の数値サマリーに変更（数値はダミー）
- OEM・業務用の導線をトップの複数箇所（ヘッダー／商品カード／専用セクション／最終CTA）に配置
- ヘッダーは常時固定、スクロールで背景がすりガラス調に変化。スマホはハンバーガーメニュー
- スクロールフェードイン、カード・画像のホバー演出、数値のカウントアップ、ページトップボタンなどのマイクロインタラクションを実装

## 構成ファイル

- `index.html` — 全12セクション（ヘッダー〜フッター）
- `styles.css` — デザインシステム（配色・タイポグラフィ・レイアウト・アニメーション）
- `script.js` — ヘッダー固定、ハンバーガーメニュー、スクロール演出、数値カウントアップ

## 写真素材について

- ヒーロー、3つの強み、商品紹介、製造工程、お問い合わせ・会社の想いの各セクションは、支給いただいたモックアップ画像から文字・UIが焼き込まれていない部分のみをトリミングして使用しています（`assets/`配下）。
- 元画像が非常に小さいサイズ（商品写真135〜165px角、工程写真120〜125px角など）だったため、拡大表示すると解像度不足で多少ソフトに見える箇所があります。本番公開時は同アングルの高解像度写真への差し替えを推奨します。
- 「品質へのこだわり」セクションの工場イラスト、OEMセクションの梱包イラストは、支給素材に該当する写真がなかったためイラストのまま据え置いています。

## 注意事項

- 掲載している数値・住所・電話番号・お知らせ・リンクはすべてプロトタイプ用のダミー情報です。
- ナビゲーションのリンク先はすべて同一ページ内のダミーアンカーです。
