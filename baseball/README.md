# タッチで打て！野球盤ゲーム（スマートフォン専用）

縦画面のスマートフォンブラウザで遊べる、シンプルな野球盤（バッティング）ゲームです。
HTML / CSS / JavaScript（Canvas 2D）のみで構成されており、外部ライブラリ・外部サーバーには依存しません。
スマホ内の写真を選んでピッチャーの顔として設定できる機能も、すべて端末内（IndexedDB / localStorage）で完結します。

## 1. 採用技術

| 分類 | 採用技術 | 理由 |
|---|---|---|
| 描画 | Canvas 2D + `requestAnimationFrame` | ビルド不要で軽量。投球・スイング・打球のアニメーションを高フレームレートで描画できる |
| 入力 | Pointer Events | マウス・タッチを同一コードで扱え、二重タップや多重処理の防止も実装しやすい |
| 音声 | Web Audio API（オシレータ合成音） | 外部音源ファイル不要。自動再生制限を考慮し、初回タップ後に `AudioContext` を生成 |
| 振動 | Vibration API | 対応端末のみ動作し、非対応でも例外を投げないようガード |
| 画像保存 | IndexedDB（不可の場合は localStorage にフォールバック） | 顔画像のような比較的大きいデータを安全に永続化するため |
| 設定・スコア保存 | localStorage | ハイスコア・音声/振動設定・遊び方確認済みフラグなどの軽量データ |
| フレームワーク | 不使用（Vanilla JS） | ビルド不要で `index.html` を開くだけで動作させるため |

## 4. ゲーム状態管理の設計

`game.js` の `Game` オブジェクトが状態を一元管理し、描画（`render` / `drawField` など）は状態を読み取るだけで、
状態を変更するのは投球・スイング・進塁などのロジック関数のみに限定しています。

- `Game.match` … `inning`（イニング） / `outs`（アウト数） / `strikes`（ストライク数） / `bases`（塁状況の配列 `[1塁,2塁,3塁]`） / `score`（得点） / `stats`（ヒット・二塁打・三塁打・本塁打数、連続出塁数、タイミング誤差の集計）
- `Game.pitch` … `phase`（`idle` / `pitching` / `resolving`）、投球開始時刻・所要時間、スイング済みフラグ
- `Game.settings` … 音声・振動のON/OFF
- `Game.totalHomeruns` / `Game.playCount` … 通算ホームラン数・プレイ回数（端末保存、タイトル画面のBEST/HR/PLAYに表示）
- `PitcherFace` … 設定中のピッチャー顔画像（カスタム画像 or デフォルト描画）
- `Screens` … 画面表示の切り替えのみを担当し、ゲームロジックには関与しない

## 5. 打撃判定ロジック

ボールがホームベースに到達する予定時刻とスイング時刻の差（`deltaMs`）を基準に判定します（`judgeSwingTiming` 関数）。

1. `|deltaMs|` に対して、`CONFIG.timing.randomness` に応じたランダムなブレ（ジッター）を加える
2. ブレを加えた誤差が `perfectMs` 以内 → **ホームラン**
3. `greatMs` 以内 → **三塁打 or 二塁打**（ランダム）
4. `goodMs` 以内 → **ヒット**
5. `okMs` 以内 → **ファウル or アウト**（ランダム）
6. それ以上 → **空振り**

タイミングが結果に強く影響しつつ、一定のランダム要素を持たせています。しきい値は `CONFIG.timing` にまとめてあり、
難易度調整や球種追加時もこの定数を変更するだけで対応できます。

見逃し（ボール通過後もスイングしなかった場合）は別途 `Game.update()` 内でタイムアウト検知し、見逃しストライクとして処理します。

## 6. ランナー進塁ロジック

`advanceRunners(bases, advanceBases)` が塁上のランナーを進める共通ロジックです。3塁側からインデックス2→0の順に処理し、
進んだ先が本塁（インデックス3以上）に達したランナーを得点として集計します。打者自身の進塁先は、この関数の結果に対して
「単打なら1塁」「二塁打なら2塁」「三塁打なら3塁」を追加で設定します（ホームランは打者も得点として加算）。

- 単打：`advanceRunners(bases, 1)` → 打者は1塁へ
- 二塁打：`advanceRunners(bases, 2)` → 打者は2塁へ
- 三塁打：`advanceRunners(bases, 3)` → 塁上走者は全員生還、打者は3塁へ
- ホームラン：`advanceRunners(bases, 4)` → 塁上走者・打者とも全員生還
- アウト：進塁なし。ストライク数をリセットしてアウト数を+1（3アウトでイニング交代）

## 7. ピッチャー顔写真選択・編集・保存機能

- 「写真を選ぶ」から `<input type="file">` で画像を選択（jpg/jpeg/png）
- 選択直後に長辺1600pxまで自動縮小してから編集キャンバスに表示（大きな写真でも固まらないようにするため）
- 円形プレビュー内をドラッグして位置調整、スライダーまたはピンチ操作（2本指）で拡大・縮小
- 「保存する」で320px四方に書き出し・JPEG圧縮した画像を IndexedDB に保存（不可の場合は localStorage にフォールバック）
- 保存した画像はページ再読み込み後も保持され、ゲーム画面のピッチャーの顔にそのまま反映
- 「リセット」で保存データを削除し、デフォルトの顔（外部画像を使わない簡易イラスト）に戻る
- 処理はすべて端末内で完結し、写真が外部サーバーへ送信されることはありません

## 8. 起動方法

ビルド不要の静的ファイルのみで動作します。

### そのままファイルを開く
`index.html` をスマートフォンまたはPCのブラウザで直接開くだけで動作します。

### ローカルサーバーで確認する場合（推奨）
```bash
cd baseball
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### スマートフォンで確認する方法
1. 上記のローカルサーバーを起動したPCと、確認したいスマートフォンを同じWi-Fiに接続する
2. PCのIPアドレス（例: `192.168.1.10`）を確認する
3. スマートフォンのブラウザで `http://192.168.1.10:8000/` を開く
4. 画面を縦向きにした状態でプレイする（横向きにすると回転案内が表示されます）
